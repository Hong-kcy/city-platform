城市商业街区虚实融合数字消费平台——功能大纲（V4.0）
一、 智能体决策与娱乐引擎（后台大脑）

此模块在V3的“决策引擎”基础上，增加了“娱乐灵感”的激发功能。目标是让用户不仅知道“该去哪”，还能发现“原来还有这种好玩的事”。

    “今日去哪”推荐卡片系统（继承V3）

        技术描述：前端唯一智能入口。后台大模型综合用户画像、位置、时间、实时热力图及商户竞价，直接生成2-3条个性化“路线推荐卡片”。

        新增：融合“主题探索路线”：推荐卡片不再仅是单点店铺，而是打包好的“半日游剧本”。例如“社恐友好一人食路线”、“闺蜜出片半日游”、“亲子放电计划”。路线可由官方预设、AI动态生成或由KOL用户共创。

    街区活动日历与订阅系统（新增）

        技术描述：聚合所有正式与非正式活动的信息流。商户可发布“周末脱口秀”，运营方可发布“国庆市集”。

        核心功能：

            “想去”提醒：用户标记后，活动前推送通知。

            “订阅”引擎：用户可订阅某类活动（如“脱口秀”），一旦有新增即推送。这是超越美团的深度运营能力。

    NPC智能体派发系统（继承并强化）

        技术描述：NPC作为“任务派发器”和“惊喜制造机”，在用户靠近特定区域时被动触发弹出。

        新增功能：“捡漏任务”：

            商户通过后台AIGC助手，一键将空场（如密室、桌游）转为限时任务：“【急】《僵尸屋》下午2:00场，半价捡漏！”

            NPC向附近用户推送：“前面那家密室店现在半价哦，运气真好！”

            优势：零开发新模块，完全复用现有任务系统，以价格激励直接解决商户翻台率问题。

二、 轻量化空间底座与游戏化交互

此模块在保持“轻、快、稳”的技术路线同时，将逛街本身变成一个充满不确定性的探索游戏。

    空间底座：真实空间底座 + 局部高保真空间 + 商业内容层 + 游戏化交互层（继承V3并重构）

        技术描述：整条商业街按保真度分层呈现，而非单一"地图"。 真实街区平面空间底座作为底层，
        重点区域叠加局部高保真空间，商业内容与游戏化交互通过动态 Overlay 叠加，不改变底层空间数据。

        分层结构：

        真实街区空间
              │
              ├── 2D地图/道路/坐标
              │       ↓
              │   真实空间底座
              │
              ├── 核心广场
              │       ↓
              │     3DGS
              │
              ├── 店铺
              │       ↓
              │   全景图/短视频
              │
              └── 平台信息
                      ↓
               NPC / 活动 / 彩蛋 /
               喧闹状态 / 任务 / 推荐

        按保真度分层：

        整条商业街
        │
        ├── 普通区域 → 2D
        │
        ├── 核心广场 → 3DGS
        │
        ├── 特色店铺 → 360°
        │
        └── 普通店铺 → 图片/视频

        第三方地图定位：真实街区平面空间底座可采用第三方地图服务，或预制/自维护的街区空间数据。
        Demo 阶段优先使用固定真实街区数据，第三方地图 SDK（高德/百度）作为后续可替换实现
        （经 Infrastructure/Provider 接入），不作为当前前置必选技术。

    空间入口切换（新增产品逻辑）

        明确用户从 2D 进入 3DGS 的路径：

        2D街区地图
              │
              │ 点击核心广场
              ▼
        3DGS空间
              │
              │ 点击店铺
              ▼
        店铺详情
              │
              ├── 360°
              └── 短视频

    “实时喧闹指数”与动态空间信息 Overlay（新增核心功能，重构）

        技术描述：基于平台实时热力数据或用户手机加速度传感器（需授权），为每个店铺生成动态的“喧闹指数”。
        喧闹指数属于空间动态信息，不改变底层地图/空间数据，通过【空间动态信息 Overlay】叠加展示。

        数据与表现分离：

        Crowd / Store Status
                ↓
        Spatial Overlay（空间动态信息 Overlay）
                ↓
        2D Map / 3DGS / Panorama

        即：数据层产生状态，空间展示层只负责表现，无论用户处于 2D 地图、3DGS 空间还是店铺全景，
        都能看到对应的动态状态。

        交互表现：店铺在任意空间形态下叠加动态表情。

            网红奶茶店排队严重：显示“😤 正在排长队，预计30分钟”

            安静的小书店：显示“😌 只有猫在睡觉，适合发呆”

        娱乐价值：为用户提供“反其道而行之”的实时决策乐趣，创造超越“搜店”的动态探索感。

        扩展性说明：动态空间信息 Overlay 不专门服务“喧闹指数”，而是通用叠加层，
        后续可承载排队状态、活动状态、捡漏任务、NPC 提示、推荐标记等。

    “扫海报”式AR交互（继承V3）

        技术描述：扫描商户门口海报/桌贴，触发AR效果。

        新增功能：“折扣盲盒”：

            用户扫描海报后，AR呈现的不是标准优惠券，而是一个“神秘盒子”。

            点击“探索一下”，可能开出“谢谢参与”、“8折券”、或极小概率的“今日免单”。

            优势：利用游戏化的不确定性，极大提升领券的趣味性和社交分享欲。

    拍图识店（视觉搜索）（继承V3）

        技术描述：拍下别人手中的产品，即可识别店铺并导航。

三、 社交货币与情感连接

此模块从“轻量共创”升级为“情感连接”，旨在用极低的成本创造能引发共鸣的社交传播内容。

    “数字留言瓶”与“情感彩蛋”系统（集成并强化）

        技术描述：将“数字留言瓶”与“街区彩蛋”结合。用户可在特定点位留下虚拟瓶子。其他用户路过时，地图上显示漂浮的瓶子，点击“捡起”查看。

        彩蛋化升级：彩蛋内容不一定是优惠券，更可以是他人的情感记忆。例如，在小巷深处捡到一个瓶子，打开是某人一年前留下的“在这里表白成功”。

        价值：这种情感彩蛋比打折券更让年轻人上头，直接打中“这条街有人情味”的核心体验。

    AIGC社交头像/打卡图生成（继承）

        技术描述：一键生成带有街区或店铺风格的数字手办、纪念头像。

    共创式街区记忆地图（继承）

        技术描述：在地图上叠加“共创层”，公开用户的数字留言瓶和AIGC打卡内容。

四、 商业化与数据引擎

此模块在保障商业闭环的基础上，进一步降低了商户创造娱乐内容、响应市场变化时的操作门槛。

    商户端AIGC一键生成助手（继承并强化）

        技术描述：为商户提供内容生成器。

        新增场景：

            一键生成“捡漏任务”：处理空场。

            一键生成“折扣盲盒”：配合AR交互，设置盲盒奖池。

            一键更新“喧闹状态”：主动向平台发布“本店现在空闲”，吸引不想排队的用户。

        解决问题：让商户能零成本地参与到平台的游戏化营销中。

    动态流量分发与竞价系统（继承V3）

        技术描述：商户可实时查看热力图，对冷区“任务赏金”进行竞价。

    积分获取与线下兑换闭环（继承V3）

        技术描述：API对接商户POS，实现积分与消费的兑换。

        新增激励：分享“情感彩蛋”内容至社交平台、参与“路线PK赛”投票等社交行为，也可获得积分。

    商户端SaaS数据看板（继承V3）

        技术描述：为商户提供数据看板，展示转化率、客流来源等。
